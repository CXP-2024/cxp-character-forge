# 眼睛精细化：对齐 MMD / 原神 PMX 的观感

适用：Tripo / Charakuru 人物（例：DeepSeek 鲸娘）眼睛与奥黛塔、沃雅妮莎等 MMD 原生眼睛同框时显得"平、糊、瞪"。2026-10-29 在 `H:/MV_making/天天天国/aibo_replica` 做成并经用户逐项认可（v15 眼睑阴影、v16 分层瞳孔、v17 发光闪点）。核心原则：**照原贴图拆层、按原位置重绘，不重画一双新眼睛**；每步都出同机位"改前/改后"对比，用户确认后再换。

## 先做对比，再动手

1. 三人同条件单眼特写：同场景/灯光/后期，静止姿势（MMD 角色 `pose_position='REST'`、表情键清零；Tripo 角色用 T 姿势帧），相机正对眼睛，距离 = 3 × 两眼间距（`scripts/eye_refine/eye_rest.py -- OUT.png 3.0 [other]`；被刘海遮住的一侧传 `other`）。
2. 逐项列差别：睫毛/眼线、虹膜层次、眼白上睑阴影、近景描边粗细。视频截图只作参考，结论以同条件渲染为准。

## 眼白上睑阴影（v15，用户认可）

参考两人眼白上半有一条随眼睑弧线的灰紫阴影，带来"凹进去"的立体感。
- 做法：`ds_lidshadow.py -- OUT.blend BAND SOFT r,g,b [BAND2 TAIL]`。以**实际镜头视角**判断眼白顶点是否露出（posed 第 0 帧网格，射线射向与 eye_rest 相同的相机位置，遮挡体 = Body），按列求露出部分的上睑线，再用**到上睑折线的垂直距离**生成顶点属性 `lid_shadow`，材质里 MULTIPLY 混色。
- 认可参数：`0.20 0.05 0.72,0.72,0.80 0.50 0.45`（贴睑一段浅灰 + 往下一段约一半强度的更浅过渡）。
- 踩过的坑（用户都指出过）：
  - 用水平方向/竖直偏移量会得到一条水平分界线 → 必须按垂直距离贴着眼睑弧线走，眼角陡处也要往下弯。
  - 颜色 0.46 太深；单段硬边过渡生硬 → 两段式、浅色。
  - 只从 +X 正前方判断露出会和低头镜头的视角对不上 → 用实际相机方向与位置。

## 分层瞳孔（v16，用户认可）

原虹膜是从插画转来的单张贴图，高光、瞳孔、反光画死且发糊。
- `iris_layers_v16.py [SHARP=1.0]` 从原贴图拆出：
  - **底层**：去掉画死的大高光与小反光（cv2 inpaint）、上下缘红/洋红描边改成虹膜蓝（保持亮度，只改色相、压低饱和），整体 unsharp 锐化。
  - **高光层**：大高光 = 低饱和亮斑的椭圆拟合（超采样抗锯齿）；小反光 = 局部更亮更淡的小块，平滑后成清晰形状；颜色取原像素分位数。
- `ds_iris_layers.py -- OUT.blend [parallax=0]`：Iris 材质改为底层 + 高光层 alpha 叠加，同一套 UV，默认高光不随视角移动（与原图一致）。
- 用户要求"不能大变"：位置、形状、颜色都照原图。**瞳孔不单独拆层**——原瞳孔边缘是很软的渐变，自动描边（饱和度阈值、亮度阈值、径向边缘）都会让瞳孔变大或变形，所以留在底层只锐化。虹膜里的紫色六边形看起来是有意的反光，保留；用户若认为是脏点再去掉。

## 发光与闪点（v17，用户认可）

- `iris_sparkle_v17.py`：下方亮区上缘放 3 颗大小、位置错开的菱形闪点 + 两颗边缘小圆点（白偏青）。**不要在高光外画青色圆圈**——用户明确否掉（`RIM = False`）。
- `ds_iris_glow.py -- OUT.blend [glitter=0.45] [glass=0.35] [emit=1.15]`：闪点层 alpha 叠加；奥黛塔 PMX 的 `tex/sp2_6.png`（彩色碎光）和 `spa/Eye_s.png`（玻璃球面）按视空间法线 matcap ADD；虹膜 emission ×1.15 让后期泛光带出一点光晕。静帧变化含蓄，动起来才"闪"。

## 眼部不要描边

原生 MMD 描边（mmd_tools 的 `mmd_edge_preview` Solidify 反向外壳）不能覆盖会动的眼部。闭眼、笑眼、wink 时眼皮折叠，很薄的描边外壳会在眼睑处露出成堆的锯齿暗线（爱包第 2609 帧）。做法：把所有眼、眉形态键会移动的顶点再向外扩 2 圈，在 `mmd_edge_preview` 顶点组里把权重设为 0；脸的外轮廓描边保留。脚本见 `scripts/eye_refine/ds_eye_noedge.py`（对象名按项目修改）。验收时同一帧对比描边开、关的特写，两者应该基本一致。

# 保形重贴图与 UV 转移

适用：外形已经认可，修复颜色、碎片、眉眼残影、颈部接缝或增加纹理精度。先锁定原模型和采用立绘。不要因“贴图差”先改脸型或重新生成整个人物。

## 先隔离问题

使用相同相机输出三种视图：灰模/线框看面与法线，无光照基色看真实纹理，最终材质看着色。必要时关掉 normal、AO、轮廓与高光逐项定位。

| 症状 | 检查与处理 |
| --- | --- |
| 三角碎块、其它部位像素混入 | 检查 UV 重叠、材质槽、活动渲染 UV、三角形顶点与 loop 对应，再考虑重画 |
| 阴影始终贴在腿上 | 无光照仍存在则可能烘进基色；灰模也出现则检查几何/法线。不要凭单张图定因 |
| 脖子肤色接缝 | 同时看头、后颈、身体的贴图与材质因子；检查重复/断开面及法线，不把所有接缝当颜色问题 |
| 头发出现肤色、脸出现蓝色 | 显示真实面归属与 UV 采样位置；不能全图删除蓝色，虹彩和眉毛可能本来是蓝色 |
| 模糊但映射正确 | 检查该部位实际纹素密度、压缩和源图质量；局部重绘/重贴或保守超分 |

一个对象可用很多 UV 岛，多个对象也能共享一张图；岛多本身不是错误。问题是碎片化妨碍绘制、密度不足、拉伸、未留 padding 或不该共享的面重叠。面部 UV 分区有利于绘画，但不能代替可变形的眼口拓扑。

## 参考和 Tripo 返图

借鉴 Charakuru：按真实贴图组导出同一构成的模型和正背面线框/轮廓指南；采用立绘提供颜色、花纹与材质，指南约束实际几何。每方向独立图，配对尺度与基线一致。没有采用背面设定的部分标为补全，不说完全忠实。

提示要点：仅画指定网格组；保持衣装剪裁、部件相对位置、遮挡与设计色；去除线框、界面和环境投影；保留适量局部色层、发束层次及材质表现，不凭空增加褶皱、首饰、发束或露出区域。身体皮肤与脸的色基一致。不要把干净误解为全身纯平色，也不要把精致误解为增加高频噪点。

上游是 Smart UV → 4K 图像参考重贴图，不重网格。**实测当前代理的 texture_model 不会重排 UV**：输入的碎 UV 原样保留（DeepSeek 脸只占贴图 2%），所以要先自展 UV 再提交，见 [component-texturing.md](component-texturing.md)；Remove Lighting 在该版本默认 OFF，可配置。当前代理不保证提供同名 UI 功能：核对 `proxy-api.md` 与实际返回参数，缺失能力明确说明。重贴图请求不能被宣传成自动生成眼睑、口腔或连续表情。

## 从返回模型恢复到原本

1. 保存 source / export / returned / assembled 的文件和校验记录，记录归一化、单位、轴向、对象矩阵、UV 名称与材料。不要两次应用轴向/缩放修正。
2. 先验证形状和面对应。Tripo 返回值可能重排顶点，UV 缝可能拆点；不能用相同顶点数或数组序号直接拷贝 UV。对称外形不能证明前后方向，方向由参考和导出记录确认。
3. **形状与面对应不变**：可借鉴 `production.py:restore_uv` 按坐标簇匹配面，支持 UV 缝拆点，按面内顶点映射写入每个 face corner 的 UV。拒绝歧义重合面、遗漏/新增面、翻转绕序或超出容差的形状。它的单张 4K 检查是上游契约，不是通用 UV 定理。
4. **仅三角化/重新分面**：不能绕过严格对应检查冒充成功。另建明确的重投影/烘焙步骤，在世界空间验证表面；三角形重心权重要与该三角的三个实际 UV loop 顺序对应。薄片、前后皮肤、睫毛和衣片不宜用无约束最近面，需按语义组、法线和距离限制。
5. **几何本身改变**：先判定能否可靠投射，再决定返工；仅包围盒缩放吻合不等于原表面恢复。
6. 原本新增 UV 层并显式接 UV Map 节点，核对 active_render。保留原 UV 及可回退材质，避免新图误接旧 UV。眼睛透明度、normal、roughness 等若原本依赖旧 UV，应保留原采样链或分别转移，不能全材质盲目换 UV。

## UV 碎片故障的实际教训

本次身体故障包含目标 UV 内部重叠：仅重排岛或只修 loop 顺序不足以解决。重建目标展开后仍须检查内部交叠，必要时拆开冲突面/岛并重新布局，然后重新烘焙。不要把多处互相覆盖的纹理直接超分。

检查岛内自交和岛间重叠；镜像共享可能是原模型有意安排，但不适合需要独立颜色的新烘焙。覆盖率与重叠统计须排除相邻三角共享边，注明采样分辨率；一次有限分辨率扫描未发现重叠，不等于数学证明绝无重叠。检查 padding、拉伸与局部纹素密度，并用棋盘格/岛色图辅助三维确认。

最终对照返回模型原生贴图与转移后的无光照渲染，用同相机看正、侧、背和近景。像素误差是辅助，背景占比会稀释全图均值；错误必须结合主体遮罩和局部区域判断。

## 局部清理与精度

### 分组高精度贴图的实际验证

同网格分组重贴可增加每组纹素预算：按原面索引导出局部副本，单独展开/重贴，恢复到原对象的新 UV 层和材质槽；不必把 API 返回顶点覆盖到原骨架网格。装饰物需要更圆滑的轮廓时，单列新增配饰版本，不能把增加几何的版本称为拓扑完全不变。原版贴图上的装饰残影与独立配饰可能同时存在，需要一起检查。

Blender 切换 Edit/Object 模式并执行 UV pack 后，必须重新按名称获取 `mesh.uv_layers[...]`，旧的 Python RNA 引用可能已指向失效/旧存储。序列化 UV 后再从实际导出的 GLB 按多边形顶点与 corner UV 复查；错误的序列化 UV 会造成大片黑块和错贴，即使纹理本身正确。原四边面和导出三角的对角线可能不同，用原多边形候选验证角点，不能只匹配原来的三角面中心。

实测 extreme 重贴可返回原生 8192 图，但不能因此称花纹完全准确。生成可能删减标志、改变背面花纹；采用的 logo 等准确性敏感区域宜保留原图/原生矢量设计，再做局部合成。返回缺少面的情况要单列：保留原面及旧采样，或重新制作；不能以缺面后的计数当完整对应通过。

灰模验证应使用新的中性材质，而不是仅复制启用中的 MToon 材质并接一个 BSDF；插件节点更新可能让“灰模”仍显示原贴图。视觉确认真正无纹理后再判断几何。

- 脖子按表面位置定位并投射到各自 UV 遮罩，统一接缝两侧的肤色和材质响应；保留衣领、嘴唇、虹彩、眉毛和发丝。局部任务可核对遮罩外像素不变。
- 去重复线前先确认是否存在独立眉毛/眼睑线网格。清掉脸图上的多余副本，保留一条合理的眼睑折线；正常双眼皮线不自动视为 bug。
- 新 UV 与贴图必须成对交付。分辨率按用途/纹素密度选择，不要求所有资产 8K；4K 到 8K 的烘焙画布只是减少二次采样损失。
- 超分可改善模糊边缘，不能修复错 UV、结构、错误配色、投影阴影或缺失拓扑。生成式超分还可能改花纹/眼型，宜在正确映射后保守试验，并检查 UV 边界和远近 mip 显示。
- 三渲二风格与贴图内容分开评估。Charakuru 的 MToon 不是原神官方着色器；渲染对比保持同一套参数，不换光照掩盖问题。

交付前重新打开保存模型检查内嵌/外部图片、UV 节点、材料与原有驱动。分别报告几何保真、映射正确、画面精细度，后一项未达标不能用前两项代替。


精修完整角色、反复出现局部污染、或静态正确但动画失真时，继续读 [贴图精修与全面验收](texture-refinement-qa.md)。该流程补充设计保真、遮挡区、左右两侧、动态遮罩及交付检查。

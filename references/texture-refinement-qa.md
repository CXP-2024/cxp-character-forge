# 贴图精修与全面验收

适用于已采用角色的保形精修，以及准备接入动作的修补模型。目的：保留角色设计和原有观感，增加可验证的纹理精度，避免静态补色在动画中错位。与 texture-transfer.md 的 UV 转移方法配合使用。

## 1. 先建立可以比较的基线

- 找到用户明确采用的模型、立绘、材质和渲染版本；不要拿最新但未认可版本当原版。记录文件哈希、对象/材质/图片/UV 对应、贴图尺寸、色彩空间、节点组、驱动、修改器、灯光和色彩管理。
- 修改用副本。锁定不在范围内的脸型、五官比例、原有肤色、衣装轮廓、花纹位置。仅贴图任务不改网格、权重、表情键或法线；确需结构修复时明确记录例外。
- 同一相机、姿态、灯光、分辨率对比。先输出正、背、左右侧、左右斜面全身，以及脸/颈、双肩、双腕、胸腰、裙边、鞋袜近景。为容易遮挡的区域临时隐藏头发或配饰检查，再恢复组装视图。

## 2. 分清故障来源再修

三套诊断图使用同一姿态：独立中性灰模（几何/法线）、实际基色输出（含修补链但无照明）、最终着色。另查看原始图片与实际 UV 采样位置，避免把材质补色误当原图已清理。

- 无光照仍有灰斑：查烘入基色的阴影、补色蒙版、UV 错配、相邻岛串色；灰色不必然是光照。
- 只有最终着色有断层：查阴影分段、AO、normal、面平滑、材质参数、色彩空间及法线接缝。正常褶皱明暗应保留，不把一切灰色涂白。
- 灰模已有破口、交叉或平面封底：这是几何问题；重贴图不能补成开口裙、连续手臂或独立安全裤。
- 接缝/碎块：查真实面归属、活动 UV、材质槽、face-corner 对应、重复面、投射误命中及 padding。不能反复盖颜色掩盖错误映射。
- 静态正常、动后异常：优先查坐标依赖、驱动、形态键及权重。比较材质链本身，不凭截图直接认定渲染器不同。
- Emission 输出不等于无光照：追踪到上游。Diffuse → Shader to RGB → 色阶/乘色 → Emission 仍然响应灯光；直接颜色/贴图 → Emission 才是不受灯光的相关路径。检查实际生效输出及节点组内部，不只看节点名字。

## 3. 选区、拆件与遮挡区

- 先做三维面选区/材质 ID 可视化，再生成 UV 遮罩。左右分别核验，不能用一侧合格推断另一侧。皮肤、布、金属、发丝、眼睛不要共用无约束颜色阈值。
- 蝴蝶结/首饰遮挡裙面时，在工作副本中暂时拆开或隐藏，分别修饰品和下面布面；检查正、侧、背面。清掉原图的饰品残影与投影污染，再组装。
- 仅纹理模糊时优先修纹理。用户要求绣花/平面纹样时不换成悬浮金属几何。若确需独立配饰，检查与布面贴合、法线方向、厚度和动作跟随，不能只检查正面轮廓。
- Tripo 适合受约束的单组件重贴图或确需重建的组件，不保证保留花纹、拓扑、尺度或轴向。返回图先在返回网格检查，再转移到原网格；不直接用整条生成手臂替换已认可身体。

## 4. 精细化而不改变设计

- 保留原 UV 与原花纹位置。金边、连续边线、logo、纽扣、刺绣的曲线、间距、粗细、接缝端点都是需要比较的地标；不要重新排一条“相似”花边代替超分。
- 先确认源图与映射正确，再进行保守超分。单纯放大画布不会恢复细节；生成式修图可能移动线条或发明结构，必须做对齐叠图、局部差异与三维检查。
- ImgGen 用原始局部贴图/展开指南及采用立绘约束。要求保留构图、边界位置、图案拓扑和主色，移除污染与模糊，不增加装饰。生成结果作为候选，只合入授权区域；遮罩外维持原像素，明确重采样造成的例外。跨 UV 缝的线条要同时检查相邻岛，不能单独修一块后出现断线。
- 分件分图可增加纹素密度，但依实际近景需求分配预算；不要让每个小饰品都占一张 8K。记录原生尺寸、超分尺寸、实际局部纹素密度以及 PNG/JPEG 压缩，不用文件体积宣称画质。
- 去污染后保留有意的明暗和材质层次。肤色以已认可面部为基准协调颈胸、双臂和手，衣服白色依据同一材质基色比较，而非强迫所有受光面最终像素完全一致。修身体不顺带改变脸部着色。

## 5. 修补必须附着于表面

不要让可动画人物的持久修补遮罩依赖当前世界坐标的 X/Y/Z 区间。这种遮罩固定在空间里，人物穿过后会把补色涂到另一部位；相同节点和相同灯光仍可得到完全不同的脸。

可选方案：
1. 将选区烘到原 UV 的独立遮罩/基色，明确 UV 名称与边缘扩展。
2. 在未变形网格上记录面角或顶点颜色/浮点属性，随蒙皮传递。硬边选区宜用 face-corner 数据，避免顶点共享导致跨边界渗漏。
3. 保存静止姿态坐标为明确命名属性，再用它计算现有遮罩；说明空间与采样时机。仅把世界坐标改成 Object 坐标不保证解决骨骼变形造成的漂移。

先在认可静止姿态比对外观，再测试角色真实平移、根旋转、抬头低头、左右转头、抬臂、屈肘和握拳。绕角色转相机不能验证此问题。导出格式不支持节点/属性时烘焙为兼容贴图，并复查导出结果。

## 6. 完整验收与交付

- 正/背/左右侧与斜面检查；上下观察领口、腋下、袖口内沿、裙边叠层、饰品背面、鞋袜接缝。临时隐藏遮挡物核对底层，没有检查的区域明确标记。
- 灰模看几何、基色看污染、最终材质看效果，三者不能互相替代。近景看清晰度，全身看是否仍像原角色；缩略图和平均误差不能证明精修合格。
- 用实际姿态短测试验证材质稳定；不必为了贴图修复默认重做物理或长片。对比同姿态、同画面尺寸，排除低分辨率放大造成的假差异。
- 检查新旧图混用、遗漏背面、左右不一致、UV 岛边缘、mipmap 串色；重新打开保存文件并在实际目标渲染器查看。内嵌/外部资源均须可解析。
- 交付采用版本、前后对比、修改部位、几何/UV 是否变化、静态和动态实际检查范围，以及剩余问题。试验材质不覆盖采用资产；压缩包只打包当前所需模型与资源。

## 已知教训：DeepSeek 动作试片（2026-10-26）

已核对源精简版与动作工程的所审计材质节点/连接/数值、灯光记录相同。脸部生效补色链使用 Geometry.Position 的世界 X/Z 范围，在移动/低头时可能覆盖到脸上的鼻口纹理。该遮罩是明确的动画不稳定来源；尚未完成固定遮罩后的同姿态渲染验收，不能标记已修好。

手臂/手掌存在 Diffuse → Shader to RGB → 颜色混合 → Emission 受光链。早先仅凭末端 Emission 判断不受光的结论错误；手部变形与明暗范围仍需独立检查。后续角色（包括 Claude）复用方法与验收，不复用 DeepSeek 的坐标阈值、蒙版或肤色数值。

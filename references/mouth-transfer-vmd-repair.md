# 原生嘴型迁移、VMD 接入与故障排查

适用于将已有 MMD 模型的嘴部结构迁移到另一个角色。2026-10-29 的项目经验；不代表完整 Charakuru 自动工作流，也不证明眼眉已完成。

## 结构和形态键

- 没有真实口洞时，先做局部重拓扑：保留参考上下口缘、口角、口内和舌头；将外围补片与目标面部连接。局部对齐 front/up、尺度和口缘地标，不能靠整脸最近点匹配上下唇。
- 为补片保存源/目标顶点对应、坐标变换、UV 和权重转移记录。只向外围接缝分散位移，核心口缘与口内不得被全局平滑压塌。先测试中性与 A，再增加 I/U/E/O、闭嘴、笑容、嘴角和舌头。
- 每个键检查 0、0.5、1；组合测试使用真实动作中同时出现的权重。形态键存在、顶点非零、视觉合格、已接动作是四个独立状态。
- 源口缘顶点误差只能证明对应几何精度，不能称为全脸或全渲染“99%相似”。

## VMD 接入

- 直接解析原 VMD 的 morph 轨道，记录名称、关键帧数量、非零数量、范围和最大权重。只有第 0 帧值为 0 的轨道不算有效动画。
- 本次 QueenCard 原动作实际使用 A/I/U/E/O、闭嘴、两种笑容和 ∧，共 9 条嘴部轨道。旧版仅映射 A 是遗漏，不能归因于作者未提供口型。
- 保留原帧号和权重，VMD morph 使用线性插值。逐帧比较原数据与 Blender FCurve（包括起止外推和帧偏移），确认没有重复旧轨道覆盖，也检查轮廓辅助对象的驱动。
- 同名或已确认对应的键直接映射；∧ 缺少同名目标时，本次用嘴角下压作语义替代，必须注明近似，不能冒称逐形精确复刻。
- Blender 新版 action 使用 layers/strips/channelbags，不能只遍历旧 action.fcurves。共享 Mesh/Key 的对象只修改一次。

## 碎片、裂缝与法线

- 分别检查真实皮肤、原生 mmd_edge_preview 反向壳和最终渲染；关闭描边后的灰模仍有缺口，就不能只归因于描边。
- 本次脸部发现 114 个面与邻面朝向不一致。按拓扑连通性核对并局部修正面绕序后，鼻下和下巴碎片消失。114 是该资产的结果，不能用于其他模型。
- 不盲目重算法线覆盖所有部件：衣物薄片、口腔、双面材质可能有各自方向要求。修复后保留顶点/形态键索引与 UV，检查张嘴、中间权重及侧面。
- 原生描边可单独辅助对象输出，但隐藏它会让渲染视口缺失脸和手描边。最终工程中需要显示完整描边时不要再全局隐藏。灰模启用背面剔除并检查真实法线，不能把隐藏壳当成修复网格。

## 嘴周肤色补片

- 查贴图、UV、材质及颜色属性的混合链。旧 MouthSkinRepair 用邻近两个点填色，取色偏红且过渡太窄，会形成口周红斑和锯齿边界。
- 从补片外健康皮肤环采样，排除唇线、口腔、鼻线和腮红高饱和区；拟合低阶平滑颜色场，向外围 smoothstep 过渡。颜色和遮罩写入随网格变形的属性，不用世界坐标锁定遮罩。
- 保留贴图的色彩空间约定，避免把 sRGB/线性转换两次；用无光基色及同灯光前后渲染验证。保护脸颊腮红、口内和舌头，不能整脸去红。

## 其他验收陷阱

- GIF 每帧单独量化会让未动的眼睛变色；用全局调色板或无损 WebP/PNG 对照排除编码原因。
- 强白边不一定是描边：检查 Layer Weight/Fresnel 驱动的 Emission 是否叠加原生描边。局部降低布料/发束边缘发光，保留金属独立材质；不要全场降曝光掩盖问题。
- 保存新版本后重新加载，核对动作、全部表情键、描边显示、缓存路径与原相机。交付列出近似映射和实际验证帧，不把抽样检查说成全片无穿插。

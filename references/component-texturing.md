# 组件拆分与分组件贴图：DeepSeek 鲸娘实例

来源：DeepSeek 鲸娘 V7 路线的实际制作（2026-10-26 至 10-28），对照了任务文件、请求 JSON 和会话记录。上承 [character-workflow.md](character-workflow.md) 的第 3 步（拆分）和第 5 步（重贴图）。脚本在 `scripts/component_tex/`；`tb_*` 系列需要先设环境变量 `TEX_JOB_DIR=<任务目录>`。

核心结论：**没有哪一种方法能贴好所有组件。** 先把组件拆细，再按组件选方法：大面积布料和皮肤用 Tripo，头发和局部细节用 Codex 生图投影，精确线条和硬件（金边、纽扣、十字）直接从几何生成。

## 1. 先拆细：组件清单

| 区域 | 拆出的组件 | 拆分方法 |
| --- | --- | --- |
| 头 | Head_Skin（脸、头皮、颈、平面眼）、Hair、Hair_Front（刘海单独拆）、女仆帽、左右耳鳍、眼睛（眼白、虹膜分层） | 按连通件加语义分组；刘海必须和头分得开（见 character-workflow 第 3 步） |
| 上身 | 上衣、纽扣、胸前蝴蝶结、上臂皮肤 | 按面写 `body_group` 属性分组（如 10 上衣 / 12 袖 / 13 腿 / 14 饰品 / 15 纽扣） |
| 手臂 | 左右袖、袖口、Hand_Skin | 手和袖口分开；补进容易漏选的手腕圈 |
| 下身 | 前裙、后裙、腿 | 前后裙分组贴，正背参考各管一面 |
| 饰品 | 裙边 4 个蝴蝶结、髋侧小蝴蝶结、后腰大蝴蝶结、左右飘带和翻边 | 小件单独拆。大蝴蝶结（1202 面）只靠连通件会漏，要加射线检测；飘带用多点射线判定，1.5 cm 内碰到另一层裙面的就算飘带层 |

拆件前先看已认可版本或参考版本（如 V11、老师版）是怎么拆的，沿用它的分组。用户要求保留原几何，**不允许用程序化方式重建组件**（女仆帽重建被否，原话“绝对不能拆出来重做”）。

## 2. 每个组件用什么贴

| 组件 | 方法 | 要点 |
| --- | --- | --- |
| 身体主体（上衣、袖、腿） | **Tripo texture_model** | 用户要求先用 Tripo 给整体身体贴一次，不能一开始就全用 Codex 投影（7 组纯 Codex 投影的版本被否）。每组：渲染原贴图 → Codex 清理成参考图 → Tripo extreme + geometry → 按面写回 UV（`tb_prep.py` / `tb_restore.py`） |
| 裙子前后 | **Tripo，正背 4 槽参考** | 只给正面时，背面靠猜（后腰蝴蝶结被画成藏青）。改用 `[{file_token:正面}, null, {file_token:背面}, null]` 才成功（`tb_restore_fb.py`）。Tripo 生成时就有的破洞先补上再贴 |
| 脸、头皮 | **Tripo，但先自展 UV** | Tripo 不会重排 UV：原来的碎 UV 让脸只占贴图 2%，结果很糊。自展 UV（脸部放大 3.5×，利用率 72%）后再跑才清楚 |
| 头发 | **Codex 多视角近景重画 + 投影** | Tripo 只给正面时，内侧变棕、发灰。改为 9 个视角由 Codex 近景重画，再投影（`proj_bake.py`）：投影考虑深度遮挡，按正对程度（facing^POW）加权，统一各视角颜色，内侧用同高度可见颜色压暗填补。之后按发色调色板校正，并修发尖拉伸 |
| 女仆帽、耳鳍 | Codex 多视角近景重画 + 投影，或直接换用已认可版本 | 以原几何的灰模为底，只用正对的视角。低置信区不再用 Tripo 补，改为从最近的清晰区域延伸。最终都换成了老师版的部件和材质 |
| 小饰品（蝴蝶结） | **单独拆出后各跑一次 Tripo extreme** | Codex 参照三张图清理参考图：原贴图渲染、灰模、设计稿裁图。蝴蝶结下面的裙面只在遮挡范围内替换像素 |
| 金边、飘带边 | **按几何程序生成** | Codex 画的金边会落到飘带中间。改为按到网格开放边的 3D 距离生成，0.5–1.9 mm 处画金边。裙摆金边用 16 个环绕近景，让 Codex 只精修金线，只替换金线和它周围一小圈（用户要求“基于原始条带”） |
| 纽扣、袖十字、铆钉 | **换成实体几何** | Tripo 生成的粗糙鼓包靠贴图救不回来。删掉旧面，换成实体金扣和金十字（`build_gold.py`） |
| 手 | **独立 UV + 平涂肤色**（沃雅妮莎式） | Tripo 会把正面颜色透到另一面：掌心出现指甲，还带阴影。改为 Hand_Skin 独立 UV、2K 平涂，只在手背一侧画指甲，不画阴影，轻度平滑（`hand_voy.py`） |
| 上臂皮肤 | 平涂肤色材质 | 去掉紫斑 |
| 局部破损（胸侧、蝴蝶结下的皮肤、鲸鱼图案区等） | Codex 局部重画（加 mask）或 harmonic 插值 | `local_paint.py`。冲突面先用 `own_island.py` 单独开 UV 岛；大块颜色缺失用 `skirt_harmonic.py` 插值，不要用纯色填 |
| 眼睛 | 原神式分层重建，或移植参考角色的虹膜 | 见 [eye-refinement.md](eye-refinement.md) |

后脑头发按发束拆开后再用 Tripo extreme 重贴（`strand_*.py`，切口 3.5 cm 内混回旧图），这只是测试，没有进入交付版。

## 3. 实际执行顺序

1. 按组导出 glb，记录 face_ids 和变换（manifest.json）。
2. 每组用同一相机渲染原贴图、灰模和 guide。
3. Codex 做精确的对象编辑：输入原贴图渲染、灰模、立绘，要求像素对位；再用红线叠加灰模轮廓，检查有没有对齐。
4. Tripo extreme + geometry：单件居中、缩放到单位大小、旋转到正面朝 −Y，参考用正背 4 槽格式。
5. 按三角形重心（KDTree）把新 UV 写回原网格（本例匹配率 99.9%）。
6. 局部问题用 Codex 近景重画后投影，加 mask 限定范围。
7. 程序化修补：harmonic 插值、调色板校正、UV padding（`mat_pad.py`）。
8. 全身改为无光照（`unlit_all.py`），灰模和贴图用同一相机放大验收。

## 4. 已踩过的坑

- **extreme 档只放大、不加细节**：返回 8K，但内容和 4K 差不多。细节要靠参考图和 UV 密度。
- **参考图里的错误会被 Tripo 照抄**：参考图里有一块藏青三角，Tripo 就照画。所以参考图要先清理干净。
- **补洞产生的细长三角面**，Tripo 会在上面画出一片糊，要用局部修补处理。
- **多视角投影各视角亮度不一**，交界会出现分界线，需要统一颜色（HARM）。
- **Codex 局部修补会顺手改掉没坏的地方**（金纹、荷叶边），必须用 mask 限定范围并羽化。
- **含皮肤的视角会触发 Codex 审核拦截**：先把皮肤涂白、加 mask，再画。
- **Blender 打包（packed）的贴图**：直接改像素再打包不会生效。要另存新 PNG，加载时设 `check_existing=False`，再做 user_remap。
- **涂色范围要看动作**：头皮涂成头发蓝时涂过了颈侧，跳舞时露出来，只好回退。
- Tripo 上传后要等导入任务完成再提交，否则会报 409；连接出错时用同一个幂等键重放，取回任务号再恢复，不要重复提交。

## 5. 给后续 agent 的规则

1. 拆件前先看已认可版本是怎么拆的；保留原几何，不程序化重建。
2. 每个要送 Tripo 的组件先自展 UV，并量一下贴图密度（px/cm），再提交。
3. Tripo 统一用 extreme + geometry，单件朝 −Y，参考用正背 4 槽格式；一次只提交一个任务。
4. 小饰品单独拆出来贴；金边、开放边描线这类精确线条，以及纽扣等硬件，优先从几何生成。
5. Codex 参考图一律带灰模，并叠红线轮廓校验对位；局部修补必须加 mask 并羽化。
6. 皮肤和手用平涂，不画阴影。
7. 每一步都用同一相机对照灰模和无光照贴图并放大检查；另存新版本，不覆盖旧版。
